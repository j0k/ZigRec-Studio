## Три требования

**Инструмент проверяет себя сам.** Ни одна задача не закрывается словами «запусти
и посмотри». Сначала стенд: синтетический экран с таймкодом, запись, автоматическая
проверка числа кадров и пропусков. Сборка и тесты — одной командой `tools/check.cmd`.

**Файл, а не полуфабрикат.** H.264 с moov в начале, корректными таймстампами
и чётными размерами кадра. Кодирование аппаратное, через Media Foundation.
Приёмка по открытию в четырёх плеерах и читаемости мелкого текста.

**Запись не мешает работать.** Горячие клавиши срабатывают при неактивном окне.
Пауза не рвёт файл. Захват 1080p60 без потерянных кадров, в пределах одного ядра.

## Критерий готовности цели

1. `tools/check.cmd` зелёный: сборка `ReleaseFast` и все тесты, включая стенд.
2. Запись 1080p60 на пять минут без пропущенных кадров, в пределах одного ядра.
3. Файл открывается в Chrome, Windows Media Player, VLC и PowerPoint; текст читается.
4. Горячие клавиши работают при неактивном окне; пауза не рвёт файл.
5. Версия бампнута по уровням закрытых тикетов, `VERSION_DATE` совпадает с датой коммита.
