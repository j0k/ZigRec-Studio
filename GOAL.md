# /goal — ZigRecStudio: экран → mp4, который открывается везде

Канонический источник: http://127.0.0.1:8000/zigrecstudio-trac/wiki/Goals/Goal_1
Трекер: http://127.0.0.1:8000/zigrecstudio-trac/

МИССИЯ: нажал горячую клавишу, снял кусок экрана, получил mp4, который без разговоров
открывается в браузере, Windows Media Player, VLC и PowerPoint. Ни звука, ни редактора,
ни аннотаций в этой цели нет. Это ровно то место, где CamStudio ломается, и ровно то,
ради чего затевается замена.

ТЕКУЩИЙ ШАГ: все десять задач цели закрыты, версия `0.1.11.1`. Работают обе формы —
окно и командная строка — на одном движке и одном наборе настроек (вики TwoForms,
там же снимок окна и раздел про стиль). Прогон 1080p60 на пять минут: 1427 кадров,
потерь 0, около 0.57 ядра, файл 115 МБ, чужой декодер прошёл его без ошибок.
Осталось от гейта одно: открыть готовый файл руками в четырёх плеерах.

ВАЖНАЯ НАХОДКА: DXGI Desktop Duplication отдаёт кадры только когда рабочий стол их
презентует. На этой машине бывает, что не презентует — работа идёт удалённо, монитор
может быть погашен. Поэтому бэкендов два: DXGI и запасной GDI, выбор автоматический.
Подробности в вики Architecture.

Язык — Zig: быстрый нативный exe без внешних DLL. Версия на выходе цели `0.4.x.x`.
Порядок ведения — каждая задача через тикет: нет тикета, нет работы.

## Четыре требования

**Инструмент проверяет себя сам.** Ни одна задача не закрывается словами «запусти
и посмотри». Сначала стенд: синтетический экран с таймкодом, запись, автоматическая
проверка числа кадров и пропусков. Сборка и тесты — одной командой `tools/check.cmd`.

**Файл, а не полуфабрикат.** H.264 с moov в начале, корректными таймстампами
и чётными размерами кадра. Кодирование аппаратное, через Media Foundation.
Приёмка по открытию в четырёх плеерах и читаемости мелкого текста.

**Запись не мешает работать.** Горячие клавиши срабатывают при неактивном окне.
Пауза не рвёт файл. Захват 1080p60 без потерянных кадров, в пределах одного ядра.

**Две формы, и обе пригодны для работы.** Консольная (`zigrec record …`, `monitors`,
`windows`, самопроверки — для скриптов, стенда и агента) и оконная (#18 окно с рамкой,
индикатором, таймером и треем; #19 горячие клавиши и пауза) на одном коде записи и
одном наборе настроек: что задаётся в окне, задаётся и ключом. Окно: запись за два
действия, состояние видно из трея, ошибка объясняется словами. Консоль: полный `--help`,
код возврата различает «записан», «записан с пропусками», «не записан».

## Стиль интерфейса

Ориентиры — Typora, nybits.com, craigslist: текст и несколько системных элементов,
ничего лишнего, одна плотная страница вместо мастеров и вкладок. Для ZigRecStudio:

- **Одно окно, всё видно сразу.** Источник, область, качество, имя файла, кнопки записи
  и паузы, таймер и состояние на одном экране, без вкладок и диалогов.
- **Системный вид, без украшений.** Обычный шрифт и элементы Windows, без иконок, тем
  и анимаций; внимание на кадре и таймере.
- **Минимум хрома.** Заголовок, короткие подписи, одна строка состояния; ошибка словами
  в этой строке, а не всплывающим окном.
- **Клавиатура наравне с мышью.** Всё достижимо горячими клавишами; окно можно не
  открывать (трей и клавиши, #19).
- **Прототип RecStudio** — макета в репозитории пока нет; когда появится, ссылка или
  снимок сюда и в #18. До этого окно #18 сверяется с описанием выше.

## Критерий готовности цели

1. `tools/check.cmd` зелёный: сборка `ReleaseFast` и все тесты, включая стенд.
2. Запись 1080p60 на пять минут без пропущенных кадров, в пределах одного ядра.
3. Файл открывается в Chrome, Windows Media Player, VLC и PowerPoint; текст читается.
4. Горячие клавиши работают при неактивном окне; пауза не рвёт файл.
5. Версия бампнута по уровням закрытых тикетов, `VERSION_DATE` совпадает с датой коммита.
6. Обе формы приняты по одному сценарию: в окне за два действия, в консоли ключами;
   читаемая ошибка при занятом файле; коды возврата; снимок окна в вики.
