# ZigRecStudio

Быстрый и компактный рекордер экрана + редактор на Zig для Windows.
Замена CamStudio с нормальным mp4 на выходе, раздельными дорожками и редактором.

## Что должно уметь

**Запись (паритет с CamStudio)**
- Захват всего экрана, области или окна (DXGI Desktop Duplication).
- Курсор с подсветкой и анимацией кликов.
- Звук: микрофон и системный звук (WASAPI, loopback), раздельными дорожками.
- Горячие клавиши: старт / пауза / стоп; таймер записи; выбор FPS.
- Аннотации: текст, стрелки, выноски поверх записи.

**Выход**
- mp4 (H.264 + AAC) через Media Foundation: аппаратный NVENC, без внешних DLL.
- Дорожки: видео, микрофон, системный звук, голос за кадром (дубли).

**Редактор**
- Таймлайн с дорожками: обрезка, вырезание, склейка, включение и выключение дорожек.
- Запись дублей озвучки поверх готового видео, выбор дубля, экспорт любого дубля.
- Точная резка: по ключевым кадрам без перекодирования, на стыках с перекодированием.

## Трекер

Trac: http://127.0.0.1:8000/zigrecstudio-trac (env `D:\pm\soft\zigrecstudio-trac`).

## Сборка

Zig 0.14+ (`winget install zig.zig`).

```
zig build
zig build test
zig build run
```
