# ZigRecStudio

Рекордер экрана на Zig для Windows. Нажал клавишу, снял кусок экрана, получил mp4,
который открывается везде. Замена CamStudio: тот пишет AVI своим кодеком, редактора
не имеет и давно заброшен.

Живёт в двух формах на одном движке записи: окно и командная строка.
Что задаётся в окне, задаётся и ключом.

## Быстро

```
zigrec ui                       окно записи (F9 — запись, F10 — пауза)
zigrec ui --tray                то же, но сразу в трее, без окна

zigrec record out.mp4 --sec 10 --area 100,100,1280,720
zigrec record out.mp4 --window "Блокнот" --fps 60 --preset text
zigrec monitors                 какие есть мониторы
zigrec windows                  какие есть видимые окна
zigrec --help                   всё остальное
```

Коды возврата: `0` записан, `3` записан с пропусками кадров, `1` не записан,
`2` неверные ключи.

## Что уже умеет

- **Захват** через DXGI Desktop Duplication, с запасным путём через GDI.
  DXGI отдаёт кадры только когда рабочий стол их презентует; на машине без
  активного дисплея (удалённая работа, погашенный монитор) он молчит, и тогда
  автоматически берётся GDI.
- **Источник**: монитор целиком, прямоугольник, окно по части заголовка.
  Область едет за окном, если его двигают во время записи.
- **Курсор** в кадре: захват отдаёт рабочий стол без него, поэтому рисуем сами.
  Подсветка под указателем, вспышка на клик разными цветами для левой и правой кнопки.
- **Кодирование** H.264 через Media Foundation, аппаратным кодировщиком.
  `moov` переносится в начало файла своими руками — штатный ключ Media Foundation
  портит данные.
- **Пресеты качества** под скринкаст: битрейт считается от числа пикселей в секунду.
- **Пауза** не рвёт файл: время простоя вычитается из меток кадров.

Звука, редактора и аннотаций пока нет — это следующие цели.

## Проверка

```
tools\check.cmd
```

Формат, сборка, тесты, релизная сборка и две самопроверки без человека:

- **захват**: своё окно рисует кадры с двоичным таймкодом, захват снимает экран,
  номер читается обратно из снятых пикселей;
- **кодирование**: кадры стенда → наш mp4 → чужой декодер распаковывает →
  мы читаем таймкоды обратно. Своим декодером проверять свой же кодировщик нельзя:
  так не заметишь ошибку, симметричную в обе стороны.

## Сборка

Zig 0.16 (`winget install zig.zig`), ABI `gnu` — заголовки Windows берутся из
mingw-w64, который везёт с собой сам Zig.

```
zig build
zig build test
zig build -Doptimize=ReleaseFast
```

## Где что

| Файл | О чём |
|---|---|
| `src/capture.zig`, `src/gdi.zig` | два бэкенда захвата и выбор между ними |
| `src/source.zig` | монитор, область, окно |
| `src/cursor.zig` | курсор, подсветка, клики |
| `src/encode.zig` | H.264 и mp4 через Media Foundation |
| `src/mp4.zig` | разбор боксов и перенос `moov` в начало |
| `src/recorder.zig` | движок записи с паузой |
| `src/ui.zig` | окно, трей, горячие клавиши, рамка выделения |
| `src/errors.zig` | ошибки словами, одни на обе формы |
| `src/testbench.zig`, `src/smoke.zig` | стенд и самопроверки |
